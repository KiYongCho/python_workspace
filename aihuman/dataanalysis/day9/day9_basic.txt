AI휴먼 9일차 Basic 과제
주제: 1차원 NumPy 배열 기초 분석

[상황]
고객센터에서 한 시간 동안 처리한 8건의 상담 대기시간(분)을 다음과 같이 기록했습니다.

12, 8, 15, 6, 20, 9, 11, 7

[요구사항]
1. 위 데이터를 NumPy 1차원 배열로 생성하세요.
2. 배열의 shape, ndim, size, dtype을 각각 출력하세요.
3. 전체 대기시간의 합계, 평균, 최솟값, 최댓값을 출력하세요.
4. 평균 대기시간보다 긴 데이터만 조건 인덱싱으로 추출하세요.
5. 모든 대기시간이 2분씩 감소했다고 가정하고 벡터 연산으로 개선 후 배열을 출력하세요.
6. 개선 후 평균 대기시간을 출력하세요.

[조건]
- Python 리스트 반복문으로 합계나 평균을 직접 계산하지 않습니다.
- NumPy 배열 연산과 집계 메소드를 사용합니다.
