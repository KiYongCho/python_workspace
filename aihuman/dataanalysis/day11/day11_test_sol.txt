주제: Pandas 데이터 조회와 전처리

문제 1
정답: `loc`

해설:
`loc`는 행과 열의 레이블 또는 Boolean 조건을 기준으로 데이터를 선택할 때 사용합니다.

문제 2
정답: `iloc`

해설:
`iloc`는 정수 위치를 기준으로 행과 열을 선택합니다.

문제 3
정답:
```python
df.isna().sum()
```

해설:
`isna()`가 각 셀의 결측 여부를 True/False로 만들고, `sum()`이 컬럼별 True 개수를 계산합니다.

문제 4
정답: `isna`

완성 코드:
```python
df.loc[df["점수"].isna()]
```

문제 5
정답: `fillna()`

예:
```python
df["담당자"] = df["담당자"].fillna("미배정")
```

문제 6
정답: `dropna()`

해설:
전체 행을 삭제할 수도 있고 `subset=`으로 기준 컬럼을 지정할 수도 있습니다.

문제 7
정답:
```python
df.duplicated().sum()
```

해설:
`duplicated()`는 중복 여부를 Boolean으로 반환하고 `sum()`은 True의 개수를 계산합니다.

문제 8
정답: `drop_duplicates()`

해설:
