Day 10 Challenge 과제 - 채용 지원자 데이터 사전 만들기
예상 수행시간: 50분

[상황]
채용 담당자가 지원자 데이터를 분석팀에 전달했습니다. 분석팀은 모델링이나 통계 분석을 시작하기 전에 각 컬럼의 구조를 파악할 수 있는 데이터 사전(Data Dictionary)을 만들어야 합니다.

[데이터]
아래 데이터를 코드에서 DataFrame으로 만든 뒤 applicants.csv로 저장하여 사용하십시오.

지원ID,지원직무,전공,경력년수,코딩테스트,영어점수
A001,백엔드,컴퓨터공학,1,82,845
A002,데이터분석,통계학,0,91,910
A003,프론트엔드,디자인,2,78,800
A004,AI엔지니어,전자공학,1,94,880
A005,백엔드,경영학,3,75,920
A006,데이터분석,수학,1,89,870
A007,AI엔지니어,컴퓨터공학,2,96,935
A008,프론트엔드,컴퓨터공학,0,84,825
A009,백엔드,전자공학,1,87,860
A010,데이터분석,경영학,2,81,905

[문제]
1. applicants.csv를 읽어 applicants_df에 저장하십시오.
2. head(), tail(), shape, columns, dtypes, info()를 이용해 데이터 구조를 확인하십시오.
3. 코딩테스트와 영어점수 컬럼을 선택한 DataFrame을 만들어 출력하십시오.
4. 숫자형 컬럼의 describe() 결과를 출력하십시오.
5. 지원직무별 지원자 수를 value_counts()로 출력하십시오.
6. 전공의 고유값 목록과 고유값 개수를 출력하십시오.
7. 모든 컬럼에 대해 아래 정보를 가지는 데이터 사전을 작성하십시오.
   - 컬럼명
   - dtype
   - 전체행수
   - Non-Null개수
   - 고유값수
   - 첫번째예시값
8. 완성된 데이터 사전을 applicants_data_dictionary.csv로 저장하십시오.
9. 다음 4개 지표를 이용해 "데이터 점검 요약"을 출력하십시오.
   - 전체 지원자 수
   - 전체 컬럼 수
   - 지원직무 종류 수
   - 코딩테스트 평균
10. 코드 마지막에 "현재 단계에서는 데이터 구조와 통계만 확인했으며, 정제 작업은 수행하지 않았다."라는 메시지를 출력하십시오.

[제출 조건]
- 컬럼별 데이터 사전 생성 부분은 for 반복문을 사용할 것
- 실습 코드의 학생 데이터와 다른 도메인의 변수명을 사용할 것
- 결측치 제거, 중복 제거, dtype 변환은 수행하지 말 것
- 생성한 CSV 2개(applicants.csv, applicants_data_dictionary.csv)가 정상적으로 저장되어야 함
