AI휴먼 과정 Day 2 단답형 테스트 풀이

[1] 정답: Interpreter(인터프리터)
해설: 작성한 Python 코드를 읽고 실행하도록 도와주는 프로그램입니다.

[2] 정답: Variable(변수)
해설: 값을 나중에 다시 사용하기 위해 붙이는 이름입니다.

[3] 정답: 대입(Assignment)
해설: 오른쪽의 값 22를 age라는 이름으로 사용하도록 연결하는 의미입니다.

[4] 정답: type()
해설: 객체가 어떤 자료형인지 확인하는 Python 내장 함수입니다.

[5] 정답: int
해설: 100은 소수점이 없는 정수입니다.

[6] 정답: float
해설: 85.5는 소수점이 있는 실수입니다.

[7] 정답: str
해설: "100"은 따옴표로 감싼 문자열입니다. 모양이 숫자와 같아도 str입니다.

[8] 정답: bool
해설: bool은 Boolean의 줄임말이며 True와 False를 표현합니다.

[9] 정답: NoneType
해설: None이라는 특별한 값의 자료형은 NoneType입니다.

[10] 정답: 2age
해설: Python 변수명은 숫자로 시작할 수 없습니다.

[11] 정답: AI휴먼
해설: name 변수에 저장된 문자열이 그대로 출력됩니다.

[12] 정답: 학습중
해설: 같은 status 변수에 "학습중"을 다시 대입했으므로 마지막 값이 출력됩니다.

[13] 정답: str
해설: data가 처음에는 int 객체를 가리키지만 이후 문자열 "백"을 다시 대입하여 str 객체를 가리킵니다.

[14] 정답: <class 'int'>
해설: type(age)는 age가 가리키는 객체가 int 자료형임을 보여줍니다.

[15] 정답: NameError
해설: 정의하지 않은 변수 이름 user_name을 사용하면 NameError가 발생합니다.

[16] 정답: A. 25 / 자료형 int
해설: 숫자 계산에 사용할 나이라면 문자열 "25"보다 정수 25가 더 적절합니다. 문자열을 숫자로 바꾸는 형변환은 다음 일차에 본격 학습합니다.

[채점 권장]

- 10~12점: type()과 자료형 구분 복습 권장
- 9점 이하: 변수 대입, 따옴표, 자료형부터 대표 실습 재실행 권장
