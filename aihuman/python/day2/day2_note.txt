[컴퓨터 언어]

1. 컴파일언어 (compile language)
- 소스코드 > (컴파일) > 목적코드 > (실행) > 기계어
- C, C++, C#, Java ...
- Java > .java 소스코드 > .class 컴파일 > 실행

2. 인터프리터언어 (interpreter language)
- 소스코드 > (실행) > 기계어
- Python, Javascript ...
- Python > .py 소스코드 > 실행


[표기법]

관례적으로 변수명, 함수명, 클래스명 등 명칭을 만들때 표기하는 방법

1. underscore (snake) : student_name (python, javascript ...)
2. camelcase : studentName (java ...)
3. hyphen : student-name


[정적타이핑과 동적타이핑]

1. 정적타이핑 (static typing)
- 변수의 타입을 지정하고 값을 할당하고 실행
- 실행 중에 변수의 타입을 변경 불가
- 컴파일단계에서 변수의 타입을 알 수 있다는 장점
- 변수의 타입이 고정되어 있다는 단점
- 컴파일 언어의 특징

2. 동적타이핑 (dynamic typing)
- 변수의 타입을 지정하지 않고 값을 할당하고 실행
- 실행 중에 변수의 타입을 변경 가능
- 변수의 타입을 유동적으로 사용할 수 있다는 장점
- 실행전에 변수의 타입을 알 수 있는 방법이 없다는 단점
- 인터프리터 언어의 특징


[진법, 진수, 진법 변환]

- 진법 : 수를 표현하는 방법
- 진수 : 진법에 의해서 사용되는 수 예) 2진수 : 0, 1
- 컴퓨터에서는 2, 8, 16진법을 사용, 일상 생활에서는 10진법을 사용
- 진법 변환
  1. 10진수를 다른진수로 바꿀때는 계속 진법수로 나눠서 꺼꾸로 쓰기
  2. 다른진수를 10진수로 바꿀때는 각 자리수에 진법수 제곱을 모두 더함
