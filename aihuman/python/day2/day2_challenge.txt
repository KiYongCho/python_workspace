AI휴먼 과정 Day 2 - Challenge 과제

[과제명]
자료형 오류 찾아 수정하기 - 다음 일차 형변환 미리보기

[목표]
type()을 이용해 자료형을 확인하고, 문자열과 숫자를 혼동했을 때 생기는 문제를 찾아 수정합니다.
※ 형변환(Type Casting)은 Day 3에서 본격 학습하므로 오늘은 최소한의 예고 수준으로 진행합니다.

[권장 시간]
30~40분

[문제 상황]
아래 데이터는 외부 입력에서 들어왔다고 가정합니다.
raw_age = "25"
raw_score = "91.5"
name = "홍길동"

[수행 과제]
1. raw_age, raw_score, name의 자료형을 type()으로 출력하세요.
2. 아래 잘못된 형변환 사례 2개를 수정하세요.
   사례 A: age = float(raw_age)
   - 나이는 정수로 관리하고 싶습니다. 더 적절한 형변환으로 수정하세요.

   사례 B: score = int(raw_score)
   - "91.5"는 소수점이 포함된 문자열이라 int("91.5")는 바로 변환할 수 없습니다.
   - 실수 점수를 유지하도록 수정하세요.
3. 수정한 age와 score의 값과 자료형을 출력하세요.
4. 다음 문장을 f-string으로 출력하세요.
   "홍길동님의 나이는 25세이고 사전점수는 91.5점입니다."
5. 코드 주석으로 다음 질문에 답하세요.
   - "25"와 25는 무엇이 다른가?
   - type()을 먼저 확인하면 어떤 점이 좋은가?
6. 선택 심화: None 값을 가진 portfolio_url 변수를 하나 만들고 type() 결과를 출력하세요.

[주의]
- 아직 try/except 예외처리는 배우지 않았으므로 사용하지 않아도 됩니다.
- 오늘의 핵심은 오류를 ‘막는 기술’보다 자료형을 ‘확인하는 습관’입니다.

[평가 포인트]
- raw 데이터가 str임을 확인했는가?
- age를 int로 바르게 변환했는가?
- score를 float로 바르게 변환했는가?
- 수정 후 type()으로 결과를 재확인했는가?
- 문자열과 숫자의 차이를 말로 설명할 수 있는가?
