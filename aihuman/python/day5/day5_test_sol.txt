AI휴먼 과정 5일차 단답형 테스트 풀이
주제: 반복문과 컬렉션

1. for문
해설: List나 Dictionary처럼 여러 데이터를 순서대로 처리할 때 for문을 주로 사용합니다.

2. while문
해설: while문은 조건식이 True인 동안 반복합니다.

3. 1, 2, 3, 4
해설: range()의 끝 값 5는 포함되지 않습니다.

4. List(리스트)
해설: List는 [ ]를 사용하며 여러 값을 순서대로 저장합니다.

5. Dictionary(딕셔너리)
해설: Dictionary는 { }를 사용하고 Key-Value 관계로 값을 저장합니다.

6. items()
해설: items()는 Dictionary의 Key와 Value를 함께 반복할 때 사용하기 편리합니다.

7. 출력 결과
0
1
2
해설: range(3)은 0, 1, 2를 만듭니다.

8. 출력 결과
10
20
30
해설: for문이 리스트의 값을 앞에서부터 하나씩 number에 저장합니다.

9. 12
해설: 0 + 2 + 4 + 6의 결과입니다.

10. 출력 결과
1
2
3
해설: count가 1부터 시작하여 3까지 출력된 뒤 4가 되면 조건이 False가 됩니다.

11. 반복이 끝나지 않는 무한 반복이 발생할 수 있습니다.
해설: count 값이 변하지 않으므로 count <= 3 조건이 계속 True로 유지됩니다.

12. scores 리스트에서 현재 반복에서 하나씩 꺼낸 점수를 의미합니다.

13. 80점 이상인 점수의 개수, 즉 합격자 수를 누적해서 저장하는 변수입니다.

14. Dictionary
해설: 학생 이름을 Key, 점수를 Value로 연결하면 이름을 기준으로 값을 관리하기 쉽습니다.

15. 반복문(for)과 조건문(if)
해설: for문으로 모든 점수를 순회하고 if문으로 80점 이상인지 판단합니다.
