[AI휴먼 Day 8 단답형 테스트 풀이]

1. 클래스(Class)
해설: 클래스는 객체를 만들기 위한 설계도입니다.

2. 인스턴스(Instance)
해설: 특정 클래스로 실제 생성된 객체를 인스턴스라고 합니다.

3. 속성(Attribute)
해설: 객체 내부에 저장되는 데이터를 속성이라고 합니다.

4. 메서드(Method)
해설: 클래스 내부에 정의된 함수이며 객체의 기능을 담당합니다.

5. __init__()
해설: 객체 생성 시 자동으로 실행되어 초기 속성을 설정합니다.

6. self
해설: 메서드 안에서 현재 객체 자신을 가리킬 때 일반적으로 self를 사용합니다.

7. 클래스
해설: class 키워드로 Student 설계도를 정의하고 있습니다.

8. 객체 또는 Student 클래스의 인스턴스
해설: Student()를 호출하여 실제 객체를 만들었습니다.

9. 속성(Attribute)
해설: self.name은 객체 내부에 저장되는 속성입니다.

10. student.show()
해설: 메서드는 객체이름.메서드이름() 형식으로 호출합니다.

11. 90
해설: 생성 시 전달한 90이 self.score에 저장됩니다.

12. RETRY
해설: 75는 80보다 작으므로 PASS 조건을 만족하지 않습니다.

13. 리스트(List)
해설: 여러 객체를 순서대로 저장하고 반복 처리하기에 적절합니다.

14. for
해설: 리스트의 각 객체를 순서대로 처리할 때 for 반복문을 주로 사용합니다.

15. 수정 예시
class Student:
    def show(self):
        print("학생 정보")
해설: 인스턴스 메서드의 첫 번째 매개변수로 self가 필요합니다.

16. 예시 답안: 여러 객체를 리스트에 모아 반복문으로 동일한 작업을 일괄 처리하기 위해서입니다.
해설: 클래스는 객체의 구조를 만들고, 리스트는 여러 객체를 저장하며, 반복문은 객체들을 순차 처리합니다.
