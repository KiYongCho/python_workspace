[객체지향 프로그래밍 개념 정리]

객체지향의 4대 개념

1) 상속 (Inheritance)
기존에 만들어 놓은 클래스를 재사용(reusing)
기존에 만들어 놓은 클래스의 변수와 메소드를 상속받아 확장(extension)
상속 해주는 클래스 : 상위(super), 기반(base), 부모(parent) 클래스라 부름
상속 받는 클래스 : 하위(sub), 파생(derived), 자식(child) 클래스라 부름

2) 다형성 (polymophism)
같은 형태인데 다른 기능을 구현
메소드 오버라이딩(method overriding)
상위 클래스의 메소드와 동일한 형태의 메소드를 하위 클래스에 정의하고
다른 구현을 하도록 함
상위에는 추상적인 것, 하위에는 구체적인 것

3) 추상화 (Abstraction)
현실세계의 복잡하고 다양한 사물이나 개념을 최대한 단순화 시킴
단, 본연의 성질을 잃어버리지 않는 선에서 단순화 시켜야 함
클래스를 정의한다는 건 어떤 사물이나 개념을 추상화시키는 것

4) 캡슐화 (Encapsulation) = 정보 은닉 (Information Hiding)
클래스 내부의 데이터 (객체의 데이터)에 대한 접근과 변경을
외부로 부터 보호

클래스 변수와 인스턴스 변수
1) 클래스 변수
클래스 내부, 생성자 외부에 만드는 변수
클래스 변수는 메모리에 하나만 생성됨
클래스 변수는 모든 객체가 값을 공유
2) 인스턴스 변수 (=객체 변수)
생성자 내부에 self.변수명 형태로 만드는 변수
인스턴스 변수는 객체마다 따로 가짐
