[AI휴먼 Day 8 Challenge 과제]
주제: 클래스 기반 학생 성적 관리 미니 프로그램

목표
- 클래스, 리스트, 반복문, 조건문, 함수, 파일 처리를 통합할 수 있습니다.
- 여러 Student 객체 중 조건에 맞는 객체를 필터링할 수 있습니다.

요구사항
1. Student 클래스를 작성하십시오.
2. name, score 속성을 저장하십시오.
3. grade() 메서드를 작성하십시오.
   - 80점 이상: PASS
   - 그 외: RETRY
4. show() 메서드를 작성하십시오.
5. 아래 5명의 Student 객체를 생성하고 리스트에 저장하십시오.
   - 김민수 85
   - 이서연 92
   - 박지훈 76
   - 정하늘 88
   - 오세진 69
6. 전체 학생 정보를 출력하십시오.
7. PASS 학생만 골라서 출력하십시오.
8. 전체 평균 점수를 계산해 소수점 첫째 자리까지 출력하십시오.
9. PASS 학생 수를 출력하십시오.
10. 결과를 day8_challenge_result.txt 파일에 저장하십시오.
    파일에는 각 학생의 이름, 점수, 결과가 한 줄씩 들어가야 합니다.
    마지막 줄에는 평균 점수와 PASS 학생 수를 기록하십시오.
11. 파일 저장 부분은 try-except로 감싸십시오.

예시 출력 일부
[합격 학생]
김민수 85 PASS
이서연 92 PASS
정하늘 88 PASS
전체 평균: 82.0
PASS 학생 수: 3

확인 포인트
- 객체 리스트를 반복문으로 처리하는가?
- 합격 여부 판단을 grade() 메서드에 모았는가?
- 평균과 합격자 수를 정확히 계산하는가?
- 파일 저장 중 오류를 처리하는가?
