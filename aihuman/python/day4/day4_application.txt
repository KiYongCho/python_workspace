AI휴먼 Day 4 - Application 과제
주제: A~F 성적 등급 판정기

[목표]
입력한 점수의 구간에 따라 A, B, C, D, F 등급을 판정합니다.

[요구사항]
1. 점수를 정수로 입력받습니다.
2. 점수가 0보다 작거나 100보다 크면 "입력 오류"를 출력합니다.
3. 정상 범위에서는 다음 규칙으로 등급을 판정합니다.
   - 90~100: A
   - 80~89: B
   - 70~79: C
   - 60~69: D
   - 0~59: F
4. if / elif / else를 사용합니다.
5. 높은 기준부터 조건을 검사합니다.
6. 최종 출력 형식은 아래와 같이 작성합니다.

[실행 예 1]
점수: 85
등급: B

[실행 예 2]
점수: 101
입력 오류

[필수 테스트 값]
-1, 0, 59, 60, 69, 70, 79, 80, 89, 90, 100, 101

[생각해 보기]
왜 60점 이상 조건을 가장 먼저 작성하면 95점이 A가 아니라 다른 등급으로 판정될 수 있을까요?
