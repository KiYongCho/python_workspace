AI휴먼 day6 단답형 테스트 풀이
주제: Python 함수(Function), 매개변수, 인수, return, Scope

[1] 정답: 함수(Function)
해설: 특정 작업을 하나의 이름으로 묶어 필요할 때 호출할 수 있는 코드 블록입니다.

[2] 정답: def
해설: Python에서는 def 키워드 뒤에 함수 이름과 괄호를 작성하여 함수를 정의합니다.

[3] 정답: 매개변수(Parameter)
해설: 함수가 입력값을 받을 수 있도록 함수 정의 부분에 작성하는 변수입니다.

[4] 정답: 인수(Argument)
해설: 함수를 실제로 호출할 때 전달하는 값입니다.

[5] 정답: return
해설: 함수 내부의 결과를 호출한 위치로 반환합니다.

[6] 정답: 10
해설: add(3, 7)은 3 + 7의 결과인 10을 반환합니다.

[7] 정답: name, job
해설: 함수 정의의 괄호 안에 있는 name과 job이 매개변수입니다.

[8] 정답: "민수", "개발자"
해설: 함수 호출 시 실제로 전달한 두 값이 인수입니다.

[9] 정답: 지역변수(Local Variable)
해설: 함수 내부에서 생성되며 일반적으로 해당 함수 내부에서만 사용할 수 있습니다.

[10] 정답: 전역변수(Global Variable)
해설: 함수 밖에서 정의되어 프로그램의 여러 위치에서 참조할 수 있습니다.

[11] 정답: RETRY
해설: 75는 80보다 작으므로 첫 번째 return이 실행되지 않고 "RETRY"가 반환됩니다.

[12] 정답: 종료됩니다.
해설: return이 실행되면 함수는 즉시 종료되고 호출 위치로 돌아갑니다.

[13] 정답: 필요한 인수의 개수가 부족하기 때문입니다.
해설: add 함수는 a와 b 두 개의 값을 필요로 하지만 10 하나만 전달했습니다. TypeError가 발생합니다.

[14] 정답: B
해설: return으로 값을 반환하면 변수에 저장하거나 다른 계산에 다시 사용할 수 있습니다.

[15] 정답: 키워드 인수(Keyword Argument)
해설: 매개변수 이름을 직접 지정하여 값을 전달하는 방식입니다.

[16] 정답: "안녕하세요"
해설: message 매개변수에 직접 지정된 기본값입니다.

[17] 정답 예: 재사용성이 높아집니다. / 가독성이 좋아집니다. / 유지보수가 쉬워집니다. / 함수별 테스트가 쉬워집니다.
해설: 큰 문제를 역할별 함수로 나누면 코드의 책임이 명확해집니다.

[18] 정답: return
해설: 계산한 average 값을 함수 밖으로 전달하려면 return을 사용합니다.
