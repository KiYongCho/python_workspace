AI휴먼 과정 - 7일차 단답형 테스트 풀이
주제: 파일 입출력 · 예외 처리 · 모듈과 import

1. File I/O
   - File Input / Output의 약어입니다.

2. r
   - read의 의미로 파일을 읽을 때 사용합니다.

3. w
   - write의 의미이며 기존 파일이 있으면 내용을 덮어씁니다.

4. a
   - append의 의미이며 기존 내용 뒤에 새로운 내용을 추가합니다.

5. 파일 닫기(close)
   - `with` 블록이 끝나면 파일을 자동으로 닫아 자원을 안전하게 정리합니다.

6. read()
   - 파일 전체 내용을 하나의 문자열로 읽습니다.

7. 줄 끝의 줄바꿈 문자 또는 문자열 앞뒤 공백을 제거합니다.
   - 파일을 한 줄씩 읽을 때 `\n`을 제거하는 용도로 자주 사용합니다.

8. FileNotFoundError
   - 읽으려는 파일이 존재하지 않을 때 발생할 수 있습니다.

9. ValueError
   - 문자열의 값 형식이 정수 변환 규칙에 맞지 않아 발생합니다.

10. try
   - 오류가 발생할 가능성이 있는 코드를 작성합니다.

11. else
   - `try`에서 예외가 발생하지 않았을 때 실행됩니다.

12. finally
   - 예외 발생 여부와 관계없이 마지막에 실행됩니다.

13. Module(모듈)
   - Python 코드를 기능별로 저장한 `.py` 파일입니다.

14. import
   - 다른 모듈이나 패키지의 기능을 가져올 때 사용합니다.

15. Comma-Separated Values
   - 쉼표 등 구분자를 이용해 표 형태 데이터를 저장하는 텍스트 형식입니다.
