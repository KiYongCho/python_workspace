AI휴먼 과정 - 7일차 Basic 과제
주제: 텍스트 학습 기록 저장·읽기
권장 시간: 30~40분

[과제 목표]
`with open()`과 `w`, `a`, `r` 모드를 사용하여 텍스트 파일의 저장, 추가, 읽기 흐름을 완성합니다.

[요구사항]
1. `day7_basic_data` 폴더를 프로그램에서 생성합니다.
2. 폴더 안에 `learning_log.txt` 파일을 만듭니다.
3. `w` 모드로 아래 3개 정보를 저장합니다.
   - 과정명
   - 오늘의 학습주제
   - 오늘 이해한 핵심 개념 1개
4. `a` 모드로 `다음에 복습할 내용` 한 줄을 추가합니다.
5. `r` 모드로 파일을 다시 읽습니다.
6. 파일 내용을 화면에 출력합니다.
7. 파일을 열 때는 모두 `with open()`을 사용합니다.
8. 실행 결과로 생성된 파일이 프로그램 종료 후에도 남아 있는지 직접 확인합니다.

[출력 예시]
과정명: AI휴먼
학습주제: 파일 입출력과 예외 처리
핵심 개념: with open()은 파일을 자동으로 닫아준다.
다음에 복습할 내용: try-except

[제출 기준]
- Python 파일이 오류 없이 실행되어야 합니다.
- `learning_log.txt`가 생성되어야 합니다.
- 기존 내용을 덮어쓰는 부분과 이어 쓰는 부분이 구분되어야 합니다.
- 주요 코드에 학습자가 이해할 수 있는 주석을 작성합니다.
