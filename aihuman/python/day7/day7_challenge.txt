AI휴먼 과정 - 7일차 Challenge 과제
주제: 함수·모듈 구조의 안전한 CSV 처리기
권장 시간: 70~100분

[과제 상황]
여러 프로그램에서 CSV 파일 읽기 기능을 반복해서 사용해야 합니다.
파일 읽기 기능을 재사용 가능한 모듈로 분리하고, 메인 프로그램에서는 분석과 출력에 집중하도록 구조를 개선합니다.

[최종 목표 구조]

```text
day7_challenge_sol.py       # 메인 프로그램
day7_challenge_utils.py     # CSV 파일 처리 모듈
```

[요구사항 - 모듈]
`day7_challenge_utils.py`에 다음 함수를 작성합니다.

1. `save_sample_csv(path)`
   - 테스트용 CSV 파일을 저장합니다.

2. `load_score_csv(path)`
   - CSV 파일을 읽습니다.
   - 정상 데이터는 `(name, score)` 튜플 리스트로 반환합니다.
   - 파일이 없으면 `FileNotFoundError`를 처리합니다.
   - 숫자 형식이 잘못되면 해당 행만 건너뛰고 메시지를 출력합니다.
   - 열 개수가 부족한 행도 건너뜁니다.

[요구사항 - 메인 프로그램]
1. `day7_challenge_utils` 모듈을 `import`합니다.
2. `day7_challenge_data` 폴더를 만듭니다.
3. `challenge_scores.csv`가 없으면 샘플 데이터를 생성합니다.
4. 모듈의 `load_score_csv()` 함수를 호출합니다.
5. 학생 수, 평균, 최고점, 최저점을 출력합니다.
6. 80점 이상 학생만 PASS로 출력합니다.
7. 데이터가 하나도 없으면 통계 계산을 하지 않습니다.
8. 예외 메시지는 사용자가 다음 행동을 판단할 수 있게 작성합니다.

[샘플 데이터]

```text
name,score
김민수,88
이서연,93
박지훈,76
최유진,85
오류데이터,점수없음
한지민,91
```

[기대 출력 예시]

```text
6행의 점수 '점수없음'은 숫자가 아니므로 건너뜁니다.
정상 학생 수: 5명
평균: 86.60점
최고점: 93점
최저점: 76점

[PASS 학생]
김민수: 88점
이서연: 93점
최유진: 85점
한지민: 91점
```

[평가 포인트]
- 메인 코드와 파일 처리 코드의 역할 분리
- 모듈 `import` 사용
- 특정 오류 행 때문에 전체 프로그램이 중단되지 않는 구조
- 함수의 반환값 설계
- 오류 메시지의 구체성
- 통계 계산 정확성
